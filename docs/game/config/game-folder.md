# Game Configuration Folder

Hexaverse creates a runtime folder in `[my documents]\My Games\Hexaverse`.
Both client and server retrieve [configuration](server.md) files from this folder.
Certain output, such as client screenshots (see [controls](../controls.md)) are also put here.

Any contained folders and files are created during first run.
Launch the server once to have its configuration files created/generated.
Likewise it is possible to simply delete any subfolders and have the server/client return the contained files to their default configuration.
