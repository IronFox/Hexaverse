# Unit Initiative

During the [motion and attack](round.md) phases, the order of unit [command](commands.md) execution is based on initiative. Higher initiative means higher priority. Units that can execute multiple instructions per round (e.g. a turret that can attack multiple times), see their initiative drop during each execution.
Units of identical initiative are prioritized in random order.
