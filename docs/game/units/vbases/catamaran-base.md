# Catamaran Base

- Cost: ![Minerals](../../../../documentation/images/Minerals.png)60
- [Initiative](../../concepts/initiative.md): 100
- Can climb 1 height level up
- Can safely fall down 2 height levels
- Operation speed multiplied by 2
- [Carrying capacity](../../concepts/vehicle.md): 15
- Base speed: 8 (naval)
- Base health: 12
- Turret range modifier: 1

Vehicles built on a catamaran base are much faster on, but also restricted to water surfaces. They are usually a good choice on planets with extensive water surfaces, but rarely anywhere else.
Naval [terraformers](../turrets/terraformer.md) can dig canals through non-water terrain, but can never leave the water surface.
