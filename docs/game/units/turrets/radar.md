# Radar

- Cost: ![Minerals](../../../../documentation/images/Minerals.png)10
- [Initiative](../../concepts/initiative.md): 100
- [Weight](../../concepts/vehicle.md): 2
- Base [scanning range](../../concepts/scanning-range.md): 7

The Radar turret is especially suited for detecting hostile entities. Such turret types are manadatory in order to see hostile forces approaching, as well as their attacks. Offensive turrets usually lack the necessary [scanning range](../../concepts/scanning-range.md) to see where they are shooting and depend on this turret type to reside in the vicinity.
