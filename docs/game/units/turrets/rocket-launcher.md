# Rocket Launcher

- Cost: ![Minerals](../../../../documentation/images/Minerals.png)15
- [Initiative](../../concepts/initiative.md): 100
- [Weight](../../concepts/vehicle.md): 3
- Base [scanning range](../../concepts/scanning-range.md): 5
- Health: x2
- Offensive turret
- [Base horizontal attack range](../../concepts/attack-range.md): 4 (Missile)
- Does not require ammunition
- 2 attacks per round
- Explosion radius: 1
- Damage: 7

Units or ground locations can be attacked if in range.
The Rocket Launcher turret intercepts hostile mobile units during their movement [phase](../../concepts/round.md). It is thus particularly well suited to defend strategically important regions.
