# Vehicle Store

- Health: 8
- Price: ![Minerals](../../../../documentation/images/Minerals.png) 40
- [Scanning range](../../concepts/scanning-range.md): 2
- Max Vehicles per Store: 4

Vehicle stores can be used to store a number of mobile units. Storage capacity increases with each additional vehicle store. Stored mobile units may be deployed in the surrounding area of any vehicle store of the same faction, allowing instant relocation across any distance.

---

Vehicle stores have evolved from a side line curiousity to a significant strategic asset if placed adequately.
Placing one store next to a [vehicle plant](vehicle-plant.md), for instance, and a second near an active war zone allows quick deployment of new units.
Furthermore, availability of units within vehicle stores is hidden from hostile sensory, even if all of your vehicle stores are currently exposed.
