# Generator

- Health: 8
- Price: ![Minerals](../../../../documentation/images/Minerals.png) 40
- [Scanning range](../../concepts/scanning-range.md): 2
- Consumes: ![Fuel](../../../../documentation/images/Fuel.png)10
- Produces: ![Energy](../../../../documentation/images/Energy.png)20

Enabled generators provide energy for the local [compound](../../concepts/compound.md). Since many structures consume ![Energy](../../../../documentation/images/Energy.png) when enabled, generators are a crucial component of any active base. Combine with [reactor core](reactor-core.md)s for increased output.
