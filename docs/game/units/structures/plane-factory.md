# Plane Factory

- Health: 40
- Price: ![Minerals](../../../../documentation/images/Minerals.png) 200
- [Scanning range](../../concepts/scanning-range.md): 2
- Consumes: ![Fuel](../../../../documentation/images/Fuel.png)20 ![Minerals](../../../../documentation/images/Minerals.png)20

Plane factories produce planes

Putting a plane factory to [sleep](../../controls.md) switches it off. Sleep is persistent: queuing new planes does not wake the factory up. Production starts once you wake it again.
