# Reactor Core

- Health: 24
- Price: ![Minerals](../../../../documentation/images/Minerals.png) 120
- [Scanning range](../../concepts/scanning-range.md): 2
- Consumes: ![Uranium](../../../../documentation/images/Uranium.png)5
- Produces: ![Energy](../../../../documentation/images/Energy.png)40

Amplifies the energy output of connected [generator](generator.md)s. Only one reactor core can be connected to any one [generator](generator.md), but multiple [generator](generator.md)s may be connected to the same reactor core. Must be placed on the same height level as the [generator](generator.md)(s) to connect to.
