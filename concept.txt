concept:
	code per technite, available to server.

automatic technite abilities:
	see two blocks far.
	collect residual light energy.
	serve as foundation for other technites to stand on.
	heat resistance (lava does not damage technite).

	
commands are executed in top-level layers:
	0: messages, scan
	1: transfer
		1.1: check+remove from storage -> buffer (either locally or remotely, but not in actual storage)
		1.2: add to remote technite. excess energy is lost
	2: end
	3: kill
		3.1 accumulate damage on target cell
		3.2 apply damage levels
	4: replace/move/spawn
		4.1 check if still alive, increase target cell change-counter
		4.2 check target cell change-counter: if 1 then perform operation. if >1 then fail
		
		
	
technite commands:
	scan [radius:float]
		detect technites, grid cells, player units in sphere of given radius.
		energy demand depends on radius.
	message [toTechnite:TUniqueID] [message:json string(1-1024)]
		send arbitrary json object to specified technite.
		range limited.
	move [toCell:HCellIdU]
		relocate local technite. consumes energy.
		can only move to neighboring cells.
		may fail if target location is occupied by technite, or non-liquid.
		motion may be involuntarily, but falling does not damage technite.
		resolution partially in parallel via layers:
			1) increase target cell change-counter
			2) check target cell change-counter: if 1 then perform operation. if >1 then fail
	transfer [toTechnite:TUniqueID] [amount:int]
		transfer specified amount of energy to targeted technite.
		range limited
		resolution in parallel via layers (executed first):
			1) check+remove from storage -> buffer (either locally or remotely, but not in actual storage)
			2) add to remote technite. excess energy is lost
	replace [cell:HCellIdU] [content:Content]
		remove/create any non-technite matter at specified cell.
		only non-technites can be replaced.
		energy cost/yield depends on matter type removed/created.
		resolution partially in parallel via layers (see move)
	end [replaceMeWith:Content]
		terminate local technite, and replace block with specified content.
	spawn [cell::HCellIdU] [repoURL] [branch/tag/commit] [message:json string(1-1024)]
	kill [TUniqueID] [damage level: energy amount]





		
		
		
		
	voteKick [technite:TUniqueID]
		vote to kick target technite from server.
		if actually kicked is replaced by clear content.
		requires >=50% of the technites on a planet to agree.
