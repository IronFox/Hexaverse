Steps to create new structures:

1) Create new const type name in shared\stringTable.h:ConstName.
2) Create structure definition module in shared space.
Defines name, basic properties server behavior.
To preserve custom data, inherit class Objects::Packable. Make sure to inherit as public

3) Create geometry (obj, mtl) in sub folder client\objects of name [object name in camelCase].obj
4) Link geometry loading in client\components\visual\scene\objectComponent.cpp:StructureHull::LoadAll()
5) Define object static commands (typically [object class]::commands) via client\components\visual\commandDefinitions.cpp:DefineAll()
	For automated working structures this can be as simple as calling DefineWorkingStructure([object class]::commands);
6) Register prototype(s) in shared\objects\prototypes.cpp:Objects::Prototypes::RegisterAll()
7) Add new structure entry in lua\attributesAndResearch.lua:StructureConfig of [type name in PascalCase]=... (often DefaultStructure([mineral price to build]))
8) If not immediately constructible, add entry MakeUnlockResearchable([group], [depencency], StructureConfig, '[type name in PascalCase]', [research cost]);
