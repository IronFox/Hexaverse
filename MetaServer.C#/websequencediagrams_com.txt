title Login Sequence



User->+Client:  Start
OS->+Consensus: Start
Consensus->+ServerRegistry: Start
ServerRegistry->+Server: Connect via SSL. Authenticate
Server->ServerRegistry: Authenticated

ServerRegistry->-Consensus: Started
deactivate Consensus

Client->+Consensus:  Login


note right of Consensus:
    *Get or create
     faction
    *Get or create
     suitable planet
     if new faction
    *Update faction
    region presence
    if new faction
end note
Consensus-->+ServerRegistry: If new:\n Colonize planet xyz\n(new units)
Consensus->-Client: Authenticated

Client->+Consensus: Get presence
Consensus->-Client: Send region presence


ServerRegistry->ServerRegistry: lookup server\n for planet xyz

Client->+Consensus: Query system xyz
Consensus->-Client: Send system xyz



ServerRegistry->Server: "createLoadWorldOrAbort xyz/type;\n createFaction ...;\n placeUnits ...;\n savePlanet ..."

alt Server is online and has diverging planet loaded
    Server->ServerRegistry: Nay
    ServerRegistry->ServerRegistry: Lookup new server\n and retry
else 
    alt No planet loaded
        Server->+DB: Get planet savegame
        DB->-Server: Savegame or nothing
        alt Has planet savegame
            Server->Server: Load savegame
        else Has no planet savegame
            Server->Server: Create planet
        end
        Server->Server: Start Service
    end
    Server->Server: createFaction
    Server->Server: placeUnits
    Server->+DB: Save planet
    DB->-Server: done
    Server->ServerRegistry: Yay
    deactivate ServerRegistry
end





alt Client faction has no sensor access to xyz
    Client->+Consensus: Access planet xyz
    Consensus->-Client: Denied
else Client faction has sensor access to xyz
    
Client->+Consensus: Access planet xyz

Consensus-->+ServerRegistry: Activate planet xyz\n for client faction abc
Consensus->-Client: Granted

ServerRegistry->ServerRegistry: lookup server\n for planet xyz .

ServerRegistry->Server: "createLoadWorldOrAbort xyz/type;\n unlockFaction ..."



alt Server is online and has diverging planet loaded
    Server->ServerRegistry: Nay
    ServerRegistry->ServerRegistry: Lookup new server\n and retry
else 
    alt No planet loaded
        Server->+DB: Get planet savegame
        DB->-Server: Savegame or nothing
        alt Has planet savegame
            Server->Server: Load savegame
        else Has no planet savegame
            Server->Server: Create planet
        end
        Server->Server: Start Service
    end
    Server->Server: unlockFaction
    Server->ServerRegistry: Yay
end


ServerRegistry-->+Consensus: Client faction\n + server URL\n + key
deactivate ServerRegistry
Consensus->-Client: Server address+key

end

Client->Server: Login (Faction ID)
Server->Client: Send random sequence
Client->Server: Send hashed secret
Server->Server: Invalidate client key
Server->Client: Authenticated\n+Units, grid, etc

Client-->+Consensus: Disconnect
deactivate Consensus
Client-->-Server: Disconnect

alt Last client disconnected
    Server->+DB: Save planet
    DB->-Server: done
    note right of Server:
        Wait grace period after
        last client disconnected
    end note
    Server->Server: End Service, flush data
    Server-->+ServerRegistry: Signal am idle
    deactivate ServerRegistry
end
