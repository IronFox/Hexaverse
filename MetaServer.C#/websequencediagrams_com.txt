title Login Sequence

participant Client
participant Consensus
participant UserDB
participant ServerRegistry
participant Server
participant DB
participant EventQueue

Consensus->+Consensus: Start
Client->+Client:  Start
Consensus->+ServerRegistry: Start
ServerRegistry->+Server: Connect via SSL. Authenticate
Server-->-ServerRegistry: Authenticated

ServerRegistry-->-Consensus:
deactivate Consensus

Client->+Consensus:  Login

alt Has certificate
    Consensus->+UserDB: Validate\n certificate
    UserDB-->-Consensus: Account data
end

alt Has no certificate or certificate was invalid
    Consensus-->Client: Not authenticated
else Certificate is valid
    Consensus-->-Client: Authenticated as\nfaction abc
end

Client->+Consensus: Request account
Consensus->Consensus: Create certificate\n+account data
Consensus->Consensus: Find suitable\n start planet\nor create such
Consensus->+UserDB: Store new account\n+certificate
UserDB-->-Consensus:
Consensus->+ServerRegistry: Colonize planet xyz\n(faction,new units)
Consensus-->-Client: Authenticated as\nfaction abc

Client->+Consensus: Get presence
Consensus-->-Client: Send region presence


ServerRegistry->ServerRegistry: lookup server\n for planet xyz

Client->+Consensus: Query system xyz
Consensus-->-Client: Send system xyz



ServerRegistry->+Server: "createLoadWorldOrAbort xyz/type;\n createFaction ...;\n placeUnits ...;\n savePlanet ..."

alt Server is online and has diverging planet loaded
    Server-->ServerRegistry: Failed
    ServerRegistry->ServerRegistry: Lookup new server\n and retry
else 
    alt No planet loaded
        Server->+DB: Get planet savegame
        DB-->-Server: Savegame or nothing
        alt Has planet savegame
            Server->Server: Load savegame
        else Has no planet savegame
            Server->Server: Create planet
        end
        Server->Server: Start Service
    end
    Server->Server: createFaction
    Server->Server: placeUnits
    Server->+DB: Save planet
    DB-->-Server: done
    Server-->-ServerRegistry: Success
    
end
ServerRegistry->+Consensus: Register possibly changed region presence\n(faction,xyz)
deactivate ServerRegistry
alt If changed
Consensus->Consensus: Update faction\nregion presence
Consensus->+UserDB: Store updated account
UserDB-->-Consensus:
alt If logged in
Consensus->Client: Send region presence
end
end
deactivate Consensus




alt Client faction has no sensor access to xyz
    Client->+Consensus: Access planet xyz
    Consensus-->-Client: Denied
else Client faction has sensor access to xyz
    
Client->+Consensus: Access planet xyz

Consensus->+ServerRegistry: Activate planet xyz\n for client faction abc
Consensus-->-Client: Granted

ServerRegistry->ServerRegistry: lookup server\n for planet xyz .

ServerRegistry->+Server: "createLoadWorldOrAbort xyz/type;\n unlockFaction ..."



alt Server is online and has diverging planet loaded
    Server-->ServerRegistry: Failed
    ServerRegistry->ServerRegistry: Lookup new server\n and retry
else 
    alt No planet loaded
        Server->+DB: Get planet savegame
        DB-->-Server: Savegame or nothing
        alt Has planet savegame
            Server->Server: Load savegame
        else Has no planet savegame
            Server->Server: Create planet
        end
        Server->Server: Start Service
    end
    Server->Server: unlockFaction
    Server-->-ServerRegistry: Success
end


ServerRegistry-->+Consensus: Client faction\n + server URL\n + key
deactivate ServerRegistry
Consensus-->-Client: Server address+key

end

Client->+Server: Login (Faction ID)
Server-->-Client: Send random sequence
Client->+Server: Send hashed secret
Server->Server: Invalidate client key
Server-->-Client: Authenticated\n+Units, grid, etc




Client->+Server: Enqueue interplanetary travel task
Server->+ServerRegistry: Send units for\n interplanetary travel\n to planet xyz
ServerRegistry-->-Server: Send resource cost
Server->Server: Pay resource cost
Server->+ServerRegistry: Dispatch units for\n interplanetary travel\n to planet xyz
Server->Server: Remove dispatched units
deactivate Server
ServerRegistry->+EventQueue: Enqueue colonization
deactivate ServerRegistry
EventQueue->EventQueue: Wait X rounds
EventQueue->+ServerRegistry: Colonize planet xyz\n(dispatched units)
deactivate EventQueue
ServerRegistry->ServerRegistry: Colonize planet\n (see top)
deactivate ServerRegistry






Client->+Consensus: Disconnect
deactivate Consensus
Client->-Server: Disconnect
activate Server

alt Last client disconnected
    Server->+DB: Save planet
    DB-->-Server:
    Server->Server: Wait grace period after\nlast client disconnected
    Server->Server: End Service, flush data
    Server->+ServerRegistry: Signal am idle
    deactivate Server
end
