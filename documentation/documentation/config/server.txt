== Planet Types ==

The server configuration loads planets as predefined templates. While their actual layout is mostly defined by fractal noise, the underlying rules are defined in separate configuration files located in ''[install]\server\config\myPlanets\[planet name].ini'' and
''[[config/game folder|user]]\server\config\myPlanets\[planet name].ini''.
Configuration files located in the [[config/game folder|user folder]] directory are prefixed with a * character.

New planet types can be created by writing new .ini files, copying and modifying existing files from the install directory, or interactively via the [[config/interactive configuration mode|interactive visual configurator]].
Once defined, use the server.ini configuration file, [[config/control console]], [[config/interactive configuration mode]], or [[config/server manager]] to load it by name.

The currently available planets may be listed using the [[config/control console]] command ''/World/showPlanetTypes''.

== Research Script ==

[[concepts/research|Laboratory research]] is controlled by a [[https://www.lua.org/|Lua script]] located in the installation folder ''[install]\lua\attributesAndResearch.lua''.

However, if a Lua file exists in ''[[config/game folder|user]]\server\config\lua\attributesAndResearch.lua'', then this will override the factory default script.

The script is loaded at [[server start]], but can be updated during runtime via the [[config/control console]] command ''/IO/reloadResearchProgram''.
Clients will receive notifications of the generated attributes, topics, and states as needed.
The script is no longer transferred to the client.

The file defines which research is possible, and how this affects unit availability and attributes.
It also allows basic **modification of all unit attributes.**
