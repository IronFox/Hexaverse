= Server Configuration =

The server can be configured in three ways.

#Edit ''[my documents]\My Games\Hexaverse\server\config\server.ini''. This file must be configured before starting the local server. Once started, the file's contents have no impact on any running server instance.
#Use the provided [[config/control console]] to manipulate a running server.
#Start a server in [[config/interactive configuration mode]]. Any server started directly from the client GUI will be started that way. Alternatively you may provide the -c parameter to the server executable at startup.


Planet templates can be changed or newly created via the config ''planets/*.ini'' files. Check out ''Template.ini'' for a documented example of a new planet.
