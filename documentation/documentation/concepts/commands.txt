= Unit Commands =

During the [[concepts/round|command phase]] players can change the active command queue of each unit they control.
Factories (e.g. [[units/structures/vehicle plant|vehicle plants]]), towers, [[units/structures/laboratory|laboratories]] and mobile units accept commands to execute during the following phases.
Most structures and mobile units allow queueing up to 16 commands each.

Commands are typically issued via their hexagonal [[controls|control buttons]].
More immediate are movement and attack commands issued by right-clicking anywhere.
This feature is available to mobile units and towers.
Use the **shift key** to queue up commands.
With the exception of very few commands (e.g. placing a unit that has been completed by a [[units/structures/vehicle plant]]), all commands are queued rather than executed immediately.

Units with empty command queues may end up doing nothing at all.
Where appropriate these units will be considered [[concepts/idle]].
Only towers are able to fill their command queue on the fly if hostile targets are within safe attacking range.
